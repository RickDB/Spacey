WELCOME TO SPACEY

Set up your storage workspace

A few steps to connect your library. Media services can be added later.

1. Secure administration

This password protects settings changes and moves to managed trash.

2. Add your storage

The container path must be mounted into Spacey. With the default Compose file, host paths appear under /host.

3. Scan behavior

Choose how many folders Spacey scans in parallel. You can change this later.

4. Optional media services

Radarr, Sonarr, and Silo identify media. MDBList adds watched status. Leave any service empty to skip it.

Ready to start

Save these settings, then scan your library from the overview. You can edit everything in Settings.
